# Support

## Getting Help

Thanks for using `scorecard-mcp`! Here are some ways to get help:

### Documentation

- [README](README.md) — project overview, install, and quickstart
- [AGENTS.md](AGENTS.md) — conventions, tooling, and the spec-driven workflow
- [openspec/](openspec/) — specifications and change proposals
- [CONTRIBUTING](CONTRIBUTING.md) — how to contribute

### Issues

If you've found a bug or have a feature request:

1. Search [existing
   issues](https://github.com/uwu-tools/scorecard-mcp/issues) first
2. If not found, [open a new
   issue](https://github.com/uwu-tools/scorecard-mcp/issues/new/choose)

### Security Issues

**Please do not report security vulnerabilities through public issues.**

See our [Security Policy](SECURITY.md) for responsible disclosure instructions.

## Response Times

This is an open source project. Response times may vary based on maintainer
availability. We appreciate your patience!

## Support Scope

| Version | Status      | Support Duration |
| ------- | ----------- | ---------------- |
| main    | Pre-release | Latest commit    |

`scorecard-mcp` is pre-1.0 and under active development; interfaces may change.
Support currently tracks the `main` branch.
